CALCULATOR NI MUISY — UPDATED EDITION

FEATURES
- Requires a name before opening the calculator.
- Shows only the balance and calculator after entering.
- No loan or reset-money buttons.
- A GCash-inspired DEMO checkout appears only after pressing equals.
- Each equals attempt has a ₱1,000 demo fee.
- The checkout is only a simulation; it is not GCash and never processes real payments.
- Demo balance starts at ₱10,000 and decreases after confirming a demo payment.

TEST ON YOUR CHROMEBOOK
1. Extract this ZIP.
2. Open the extracted calculator-ni-muisy folder in VS Code.
3. Open Terminal in VS Code.
4. Run: python3 -m http.server 8000
5. Open http://localhost:8000 in Chrome.

INSTALL ON ANDROID
This is a web app/PWA, not a native APK. To install it on Android, it must be hosted on HTTPS. Open the hosted site in Chrome and use the browser menu's Install app or Add to Home screen option.

IMPORTANT
The checkout screen is intentionally marked DEMO ONLY. It does not collect GCash details, connect to GCash, or make real transactions.
